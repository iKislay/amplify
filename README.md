# Amplify

A VS Code extension to turn short, lazy prompts into highly detailed software engineering instructions.

## Features
- **Expand Selection**: Highlight a short instruction and press `Ctrl+Alt+C` (or `Cmd+Alt+C`) to replace it with a detailed prompt.
- **Quick Expand**: Press `Ctrl+Alt+C` with no selection to enter a prompt, which will be expanded and copied to your clipboard.
- **Customizable**: Change the system prompt in settings to fine-tune how prompts are expanded.

## Usage
1. Open a file.
2. Type a short prompt like "implement a rust web server with axum".
3. Highlight it and press `Ctrl+Alt+C`.
4. Watch it turn into a structured prompt!
